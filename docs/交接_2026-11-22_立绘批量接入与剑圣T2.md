### 4.2 立绘几何规则（重要）

立绘在游戏里**高度恒等于幕布高度**（`p_sc = bh / tex.height`），宽度随图比例：
- 比例 0.6~0.9 → 完整落在幕布内（推荐）；
- 比例 > 1（横构图）→ 横向溢出台面（暴食魔女第一版就是这样，用户要求改）。

特例：暴食魔女的棺材是**斜的**，用户要求「保留棺材 + 旋转摆正 + 底部平切」：
旋转 +10°（PCA 求主轴在这张图上失效，两翼面积主导，改成候选角对比图肉眼挑），
旋转前必须用大半径模糊把透明区的 RGB 填满，否则边缘会挂一圈黑边。

### 10.1 终结动画为什么曾经「先播光柱、再播终结」（2026-11-22 根因）

**现象**（用户原话）：「刚才还是先播放的二段动画，再播放的终结特效」。

**根因**：`BallroyBeam.WillBeFinisherKill` 用**死后的判据**做**命中前**的判断 ——
`ShaulaStrike.IsFinisherNow` 里没有排除目标自己（`left.Any(e => !e.IsDead && e.CurrentHp > 0 && !e.IsSecondaryEnemy)`），
而出牌那一刻目标**还活着**、就在 `HittableEnemies` 里 → 恒返回 false → 恒判「不是终结」→ 恒播普通光柱；
怪死后钩子再用同一个判据（此时目标已死）→ 终结为真 → 再播一遍终结。**每次终结必杀都是双份演出**。

日志证据（`godot.log` 16:44 那局，两发延迟连杀）：

```
[Subaru] ballroy beam: tier=2 at (1630,728) ...        ← 第一发杀死 A（A 不是最后一只 → 静音）
[Subaru] enemy defeat: ballroy normal kill -> silent
[Subaru] ballroy beam: tier=2 at (1257,709) ...        ← 第二发：预测又返回 false，光柱照播
[Subaru] ballroy finisher: start (..., finisher=True)  ← 死后钩子才判出终结 → 第二段演出
```

**定论**：新增 `ShaulaStrike.WillBeLastKill`（唯一区别：`!ReferenceEquals(e, target)`），
命中前一律用它，`IsFinisherNow` 只留给死后/`MonsterCards` 用。

### 10.2 现在的分流（2026-11-22 用户定：终结特效 → 终结攻击动画）

| 情况 | 这一击的攻击动画 | 死亡阶段 |
|---|---|---|
| 打不死 | 普通光柱（1/2/3 档） | — |
| 打死，场上还有别的怪 | 普通光柱 | **完全静音**（通用碎裂音 + `KillEffect` 全拦） |
| 打死，且是最后一只（终结） | **终结动画本体**（蓄力 → 白屏 → 黑柱砸下，返回时正好是命中帧） | 静音，只 `await` 白屏收尾，别让奖励界面压在白屏上 |

- 结构上拆成两段：`PlayFinisherAttackAsync` 等**到黑柱落地**就返回（调用方在这之后结算伤害），
  定格 520ms + 白屏退去 220ms 由 `RunFinisherTailAsync` 自己跑；
