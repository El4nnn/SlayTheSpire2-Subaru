## 7. 环境备忘（这台机器专属的坑）

- 构建/部署/抠图都必须用 **bundled python**（`~\.dsh\dsh-runtimes\...\python.exe`，带 PIL/numpy）；
  系统 `python` 没有 PIL。
- pip 直连会卡死 → 装包用 **`_tools\uv\uv.exe`**，并设 `UV_CACHE_DIR` 到工作区。
- rembg 模型缓存要 `U2NET_HOME=_tools\rembg\models`。
- **Python 子进程不能写 D 盘**（2026-11-22 实测：`os.makedirs` / `open` 都是 `WinError 5`，同一路径 PowerShell 可写）→ 部署改用 `_tools\deploy_mod.ps1`。根因还没查到底，先按现象绕开。
- 中文文件写入用编辑器工具或 Python 的 UTF-8 读写，**不要** `Get-Content -Raw` + `Set-Content`（会变乱码）。
