## 二、权能（Authority）

### 2.1 死亡回归（Return By Death / 死に戻り）

昴的核心能力，由**莎缇菈**赐予。

- **机制**：死亡后立即回到一个「存档点」，无延迟
- **存档点**：死亡前设定，**不可预知、不可控**
- **次数**：目前没有任何证据表明存在回归次数上限
- **本质**：被视为一种权能，但对应哪种「魔女因子」尚无定论

**三大惩罚（说出口的代价）：**

1. **魔女之手**：企图说出真相时被捏住心脏，剧痛，某些情况下直接死亡
2. **转移惩罚**：若执意告诉自己重要的人，魔女会转而捏住**对方**的心脏致死
   - 目前明确会死的对象只有爱蜜莉雅
   - 所以不能当作攻击手段使用
3. **魔女瘴气**：回归后短时间内身上瘴气变浓，**瞬间吸引附近魔兽**，即使魔兽知道是诱饵也会靠近

### 2.2 怠惰的权能（Authority of Sloth）

击败**培提奇乌斯·罗曼尼康帝**后获得。

- **不可视之神意（Invisible Providence）**
  - 集中注意力 → 创造一个可穿透物体的**手形不可视力场**，进行物理干涉
  - 与培提奇乌斯的「不可视之手」相似，但昴**只能控制一只手**
  - 范围和破坏力都很小，从**胸口**而非背部伸出
  - 远弱于历代怠惰司教

### 2.3 强欲的权能（Authority of Greed）

击败**雷格鲁斯·科尼亚斯**后获得，昴是目前持有者。

- **柯爾·雷欧尼斯（Cor Leonis / コル·レオニス）**
  - 雷格鲁斯权能「小小的王」的**逆向形式**
  - 可**接管他人身体与精神上的负担**，转移给自己或其他人，从而提升他人战力
  - 仅对与昴**建立了情感连接**的人有效
  - 激活时可感知对方为「光点」，能获得**相对位置与情绪状态**
  - 拉姆评价：与「狮子的心脏」的**共感**特性相似

### 2.4 魔女因子

据**夏乌拉**所说，昴体内至少有**三种魔女因子**，其中两种为「怠惰」与「强欲」，第三种未明（死亡回归的归属存疑）。

## 三、魔法

### 3.1 阴属性魔法

- 过去可使用阴属性魔法，**门崩坏后无法独自施法**
- 仍可在**碧翠丝**的帮助下有限度使用
- 与贝蒂合创了三种阴魔法，**每种每天只能使用一次**，第三种仍未完成

### 3.2 纱幕（Shamak / シャマク）

- 让敌人陷入黑暗、**扰乱感官**
- 门崩坏前唯一能用的魔法，用了很多次，自称「纱幕桑」

### 3.3 与贝蒂的合体魔法

| 魔法 | 全称 | 效果 |
|---|---|---|
| **E·M·T** | 爱蜜莉雅炭·真是·天使 | 「绝对还原魔法」：以昴和贝蒂为中心，直径几十米的球形区域内**所有魔法被还原为玛娜**；对不依赖玛娜战斗的敌人无效 |
| **E·M·M** | 爱蜜莉雅炭·真是·女神 | 「绝对防御魔法」：贝蒂用阴魔法干涉时空，让昴与世界**错位半步**；发动期间昴**无法移动**，但免疫屏障外一切干扰；可持续到玛娜枯竭；类似雷格鲁斯的强欲权能，但没有心跳停跳的风险 |

### 3.4 租借·唤火（Rental Goa）

- 与**伊亚**临时契约即时使用的火焰法术
- 火焰很弱，用于给培提奇乌斯浇油后点火

### 3.5 精灵术

- **精灵亲和力**极高，精灵愿意亲近他
- 与人工精灵**碧翠丝**签订契约，成为「精灵骑士」，但**不是真正的精灵使**
- 契约四条件：
  1. 昴不可与其他精灵签订契约
  2. 贝蒂不可自己产生玛娜
  3. 贝蒂不可使用大气中的玛娜
  4. 贝蒂只能从昴身上吸取玛娜
- 圣域篇之后可正式使用精灵术

### 3.6 有缺陷的门 / 玛娜中毒

- 门在魔兽事件未愈时强行施法 → **完全摧毁**
- 后果：无法排出玛娜，**不能独自施法**，有**玛娜中毒**致死风险
- 贝蒂通过**身体接触**吸走过量玛娜，替他续命

## 八、写卡时的注意事项

1. **昴很弱**：身体能力只是「普通人里偏高」，所有强牌都必须付出代价（诅咒、血量、行动）
2. **死亡回归的惩罚**是设定核心，别只做「复活」不做代价
3. **贝蒂是人工精灵**：契约有明确限制（不能自己产玛娜、只能吸昴的），做成资源约束比做成纯 DPS 更还原
4. **不可视之神意很弱**：一只手、范围小，别做成大招
5. **IF 线是平行世界**：大罪牌可以强，但要有「走上歧路」的代价感
