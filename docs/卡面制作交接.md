## 0. 一句话流程

```
找图 → 裁成 1000x760 比例 → 存成 <卡牌id小写>.png → 放进 images/card_portraits/
     → 同样内容缩成 500x380 放进 images/card_portraits/big/…（注意方向，见 §3）
     → Godot 导入 → 打包 → 拷进游戏 mods 目录
```

## 1. 卡面文件放哪、叫什么

| 用途 | 路径 | 尺寸 |
|---|---|---|
| 手牌/牌堆（小图）| `src\Subaru\Subaru\images\card_portraits\<id>.png` | 500×380 |
| 放大查看（大图）| `src\Subaru\Subaru\images\card_portraits\big\<id>.png` | 1000×760 |

> 注意：代码里 `CardImagePath` 查的是 `card_portraits/`，`BigCardImagePath` 查的是 `card_portraits/big/`。
> 历史上我把这两个写反过一次，结果是手牌显示大图。小图在**外层**，大图在 **big** 子目录。

**文件名规则**：卡牌 id 去掉 `SUBARU-` 前缀再转小写，加点号前原样保留。

```
SUBARU-LILIANA_FRIEND  ->  liliana_friend.png
SUBARU-EL_MINYA        ->  el_minya.png
```

找不到对应文件时会回落到 `card_portraits/card.png`（占位模板），日志里打 `Could not find card image path`。

**比例固定 1.3158（1000/760）**。所有源图都要裁到这个比例，否则会被拉伸变形。

## 3. 裁图规则（已用过的三种）

源图比例几乎都不会正好是 1.3158，必须裁。按主体位置选一种：

| 模式 | 适用 | 做法 |
|---|---|---|
| `center` | 主体居中 | 左右各裁一半，或上下各裁一半 |
| `top` | 竖图、脸在上半部 | 纵向从 y=6% 处开始裁，保住头顶 |
| `right` / `left` | 主体偏一侧 | 贴那条边裁，另一边全裁 |

**放大上限 2 倍**：源图宽度不足目标一半时不要硬拉。例：莎提拉那张源图只有 370px 宽，
按 1000 出图要放大 2.7 倍会很糊，所以只出到 740×562（2 倍），游戏里会自己缩放。

## 4. 颜色处理：卡面**不做** 2D 压色

角色立绘和图标走的是「饱和 ×1.4 + 明度压 5 档」，那是为了把 3D 渲染压平。
卡面是手绘动画截图，本身就是平的，压色只会毁掉肤色和渐变，**所以卡面一律按原样导入**。

工程里有个自动压色脚本 `bake_all.py`，它按 `STATE.json` 里的内容哈希判断哪些文件要处理。
卡面导入后必须登记成「最终成品」，否则下次跑它会被压色。登记方式见 `install_cards.py`。

### 5.2 装进工程

```powershell
& $py 'C:\Users\Elan\Desktop\塔2mod\docs\卡面脚本\install_cards.py'
```

它做三件事：写出 big/ 和小图、按 500×380 / 1000×760 出图、把两个文件登记进 `STATE.json` 的最终名单。

### 5.3 Godot 导入（新 png 必须做，否则打包进去的是空图）

```powershell
$env:TEMP=$env:TMP='C:\Users\Elan\Desktop\塔2mod\_tools\tmp'
$exe='C:\Users\Elan\Desktop\塔2mod\_tools\megadot\MegaDot_v4.5.1-stable_mono_win64.exe'
Start-Process -FilePath $exe -ArgumentList '--headless','--path','src\Subaru','--import' `
  -WorkingDirectory 'C:\Users\Elan\Desktop\塔2mod' -Wait -NoNewWindow
```

> **必须用 `Start-Process -Wait`，不能直接 `& $exe`**：这个 Godot 是 GUI 子系统程序，
> PowerShell 直接调用不会等待，导入会在后台跑而你以为完成了。
> 另外不要用 `| Select-Object -First N` 接它的输出，管道提前关闭会把它杀掉。

### 5.4 打包 + 部署

```powershell
Set-Location 'C:\Users\Elan\Desktop\塔2mod'
Remove-Item 'dist\Subaru\Subaru.pck' -Force -ErrorAction SilentlyContinue   # 必须删，否则跳过导出
& '.\_tools\dotnet\dotnet.exe' publish 'src\Subaru\Subaru.csproj' -c Release --no-restore

$dst='D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\Subaru'
Copy-Item 'dist\Subaru\Subaru.dll' $dst -Force
Copy-Item 'dist\Subaru\Subaru.pck' $dst -Force
Copy-Item 'dist\Subaru\Subaru.json' $dst -Force
```

- `MSB3073 ... 已退出，代码为 -1` 是**正常**警告，不是失败，只要 `exit=0` 就行
- `error STS001` = 自定义枚举缺本地化

> **`dotnet publish` 前必须先改 TEMP**（2026-11-12 实测）：
> 本机 dotnet 在 `%LOCALAPPDATA%\Temp` 下建临时目录会被拒（`UnauthorizedAccessException`），
> 连带 NuGet 拿不到 `%TEMP%\NuGetScratch\lock\...` 的锁，卡 **47 秒**后报
> `MSB4236: 找不到指定的 SDK「Godot.NET.Sdk/4.5.1」`。
> 这是假象，**SDK 没丢，别去重装**。加一行就好：
>
> ```powershell
> $env:TEMP=$env:TMP='C:\Users\Elan\Desktop\塔2mod\_tools\tmp\dotnet_tmp'
> ```
>
> 加完从「47 秒失败」变成「4 秒成功」。Godot 那步的 TEMP 重定向也是同一个原因。

## 7. 常见坑

1. **大小图放反**：小图在 `card_portraits/`，大图在 `card_portraits/big/`。
2. **文件名大写**：代码走的是 `.ToLowerInvariant()`，`EL_MINYA.png` 查不到，必须 `el_minya.png`。
3. **比例不对**：不是 1.3158 会被拉伸。
4. **放大过头**：源图太小就按 2 倍上限出图，别硬拉到 1000。
5. **忘了导入**：新 png 不跑 §5.3 的话，打包进 pck 的是空的或旧缓存。
6. **忘了删 pck**：不删 `dist\Subaru\Subaru.pck` 的话，`publish` 会跳过导出，改动不生效。
7. **跑 bake_all.py 前没登记**：会被当成新美术压色，卡面就毁了。
8. **dotnet 用默认 TEMP**：见 §5.4 的提示框，会伪装成「SDK 没装」。两个脚本跑完记得删掉 `_tools\tmp\dotnet_tmp` 里的东西也无所谓，它只是中转目录。
