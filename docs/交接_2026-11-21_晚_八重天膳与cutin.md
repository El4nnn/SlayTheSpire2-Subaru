## 4. 关键技术结论（都验过）

### 4.1 立绘「定格 → 等攻击播完 → 退场」

- 需求原话：「和夏乌拉一样，播放完攻击动画再退场」。
- 做法：`CutIn.PlayAndHoldAsync` 把 `run.Held = true` → `ExitMs(run)` 返回 `+∞` → 所有层的退场进度恒为 0（立绘定格）；
  `Session.Exit()` 把 `ExitAt` 写成当前时刻才开始退场。`DriveAsync` 的生命周期改成**每帧按 `ExitMs` 重算**（原来是开局算死的 `total`）。
- 兜底：没人 `Exit()` 时最多定格 `MaxHoldMs = 9000ms`。
- 调用方（`PuppetStrings`）：`fx?.Finish(); await ScreenCut.WaitReleasedAsync(); cutIn?.Exit();`
- **第一版做反了**：曾经让「攻击动画在立绘退出的瞬间开始」（`PlayToExitAsync`），用户当场否掉，那个 API 已删。

### 4.2 「有些战斗盖不满屏」的根因

`RoomVfx.Attach` 原来只减了容器的 `Origin`，**没管 `Scale`**。播放时若房间容器的画布变换带缩放，按「一屏大小」画的矩形就不再等于一屏 —— 所以是**按战斗（房间）不同**而不同，不是按怪不同。
修法：`RoomVfx.AlignToScreen(root, container)`，`root.Scale = 1/scale`、`root.Position = -origin/scale`；另外全屏矩形统一改成「2 倍面积、中心对齐」（`Position = -view*0.5, Size = view*2`）。

### 4.3 终结演出的「洞」要跟身体大小走

`ShaulaFinisher` 原来 `radius = max(46, rect.H * 0.26)`，**又乘了一次 `scale`**。`rect` 来自 `GetGlobalRect()`，已经是 view 空间的像素 → 1920 宽下多放大 1.5 倍，加上 46 的绝对下限，小怪身上圆比身体还宽。
现在：`radius = clamp(min(rect.W, rect.H) * 0.30, 6*scale, view.H*0.13)`（短边 × 0.30 → 直径约短边 60%），不再乘 `scale`。3:2 的身体在大怪上几乎和改前一样。

### 4.4 底色的时长

- 普通攻击：爆开后再留 `NormalHoldMs = 100ms`（用户：「出现时间太短」）。
- 终结：`ShaulaFinisher.TotalMs = 90+500+520+220`，开演时调 `ShaulaStrike.KeepBackdropForFinisher(TotalMs)` 把底色的淡出时刻推到演出结束（最后一帧才淡完）。
- 兜底 `FinisherFallbackMs = 1100ms`（终结没接管时），硬上限 `MaxLifeMs = 8000ms`。

### 4.5 碎片要「散开」

失败版本：`dist = radius * (0.4~2.0)`。圆改成按身体大小之后半径只剩几十像素 → 碎片挤在 100px 内。
现在：扩散尺度 `max(radius*2.6, view.H*0.22)`，方向用**金色角均分** + ±0.35rad 抖动，碎片错开 0~60ms 起飞，
飞行 `ShatterMs = 520ms`（Cubic Out）+ 轻下坠（终点 y += 0.22×距离），**飞行到 45% 就开始淡**（`TailMs = 220ms`）。
