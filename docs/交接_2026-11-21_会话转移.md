## 3. 本次会话做完的事（按时间）

1. **操丝术切屏演出**（新文件 `Vfx/ScreenCut.cs` + `_anim/review/screen_cut.html` 预览台）
   - 全屏 `ColorRect` + `canvas_item` shader，`hint_screen_texture` 读实时画面 → 4 条线切 5 块 → 每块整体平移 → 缝里露虚空 → 合拢。
   - 参数（用户定）：基准角 **90°（横条）**、散布 0.77、角度抖动 ±5.5°、位置抖动 0.1、每刀 **8.5 px**、过冲 1.25、
     出线 70 ms / 分开 85 ms / **停留 420 ms** / 合拢 160 ms；线宽 1.3、光晕 8 px×0.25、缝光 0.92、刀光白闪 **0.30（45 ms 高斯）**。
   - 每刀由**伤害段**触发（`Cut()` 挂在每段伤害之前），每次打牌线条重新摇。
2. **打击特效总开关**（设置 → 特效 →「打击特效」，默认开）
   - 管：顿帧、抖屏、镜头推、光爆、受击闪白、弹幕（含出伤同步）、切屏、卡牌虚化。
   - 不管：打击音效、击杀特效（各有独立开关）、死归紫光/死亡动画。
   - 实现：四个系统的 `Enabled` 改成属性（`自己的开关 && 总开关`）；`HitFxEnabled` 用 `bool?` 兼容旧存档。
3. **魔女瘴气不吃缓冲 / 滑溜**（`Patches/MiasmaBleedPiercePatch.cs`）
   - `MiasmaBleed.Enter()` 作用域 + 4 个 prefix（缓冲的 `ModifyHpLostAfterOstyLate` / `AfterModifyingHpLostAfterOsty`、
     滑溜的 `ModifyHpLostAfterOsty` / `AfterDamageReceived`）。
   - 连带：`Spike.CapLethalDamage` 里「有缓冲/滑溜就不截断」两条放行要排除瘴气窗口，否则 1 血被瘴气打死不会死归。
4. **临时测试牌补丁**：先加「过路魔」、后换「操丝术」进初始手牌测切屏，发版前**整文件删除**。
5. **发版**：写 `更新说明_0.3.27.md`、改 `workshop.json` 的 changeNote、铺 `content\`、建 `release\Subaru_v0.3.27\`、上传工坊。

## 5. 环境与发版流程（照抄即可）

```powershell
$env:TEMP="$pwd\_tools\tmp"; $env:TMP="$env:TEMP"
$env:NUGET_PACKAGES="$pwd\_tools\nuget"; $env:NUGET_HTTP_CACHE_PATH="$pwd\_tools\nuget\http"
$env:DOTNET_ROOT="$pwd\_tools\dotnet"
if (Test-Path dist\Subaru\Subaru.pck) { Remove-Item dist\Subaru\Subaru.pck -Force }
& "$pwd\_tools\dotnet\dotnet.exe" publish src\Subaru\Subaru.csproj -c Release --no-restore
python _tools\deploy_mod.py
```

发版四步（`release\workshop\Subaru\更新流程.txt` 有原文）：改 `version` → `content\` 覆盖三件 →
改 `workshop.json` 的 `changeNote`（**回复里必须贴中文 + 日文代码块**）→ 跑 `upload.bat`。

- `publish` 经常报 `MSB3073 … 已退出，代码为 -1` 但其实 pck 已经生成 —— **以 pck 是否存在 + md5 为准**。
- 上传日志里 `k_EItemUpdateStatusInvalid` 是常态，判据是 `Successfully uploaded` + exit 0。
- 工坊 Web API 核验（`file_size` / `time_updated`）在本机**直连不通**（`WinError 10061`，要代理）；没有代理时以 uploader 日志和工坊页面为准。
- IL 取证：`_tools\dotnet\dotnet.exe _tools\IlDump\bin\Release\net9.0\IlDump.dll <dll> <Type> [Method]`，
  结果写到 `_tools\IlDump\bin\Release\net9.0\il_out.txt`；**dump 里的地址比真实偏移大 1**。
- 无头截图核对预览台：`msedge.exe --headless=new --disable-gpu --no-sandbox --screenshot=… "file:///…?t=毫秒"`。
