## 这次做完的事（0.3.0 → 0.3.1，已上传工坊）

### 文森特状态合并（结构）

- 删掉 `SubaruCode\Powers\VincentContractPower.cs`
- `SubaruCode\Powers\VincentPower.cs` 改成**唯一**的状态能力：既显示、也执行「每 2 回合塞 1 张九神将」
- `SubaruCode\Cards\VincentContract.cs` 只 `Apply<VincentPower>`，`Amount = IsUpgraded ? 2 : 1`
- 状态改名 **鲜血帝 / Blood Emperor**（`SUBARU-VINCENT_POWER.*`），旧的 `VINCENT_CONTRACT_POWER` 三条 key 删除

为什么升级信息放 `Amount`：回档恢复能力只恢复 `Amount`
（`BattleSnapshot.cs` 附近 `PowerCmd.Apply(canonical, creature, saved.Amount, ...)`），实例字段会丢。
`Amount` 为什么不显示：`NPower::RefreshAmount` 只给 `PowerStackType.Counter` 写数字，`Single` 恒空。

### 鲜血帝图标

- 用户给的图（金线稿 + 纯黑底）→ `_tools\gen_vincent_icon.py`：亮度 alpha 键控（24/110）→ 裁 bbox → 内容 86% → 256 / 64
- 产物：`images\powers\vincent_power.png`（64）+ `images\powers\big\vincent_power.png`（256）

### 缓慢可以叠层（改的是原版）

- 新增 `SubaruCode\Patches\SlowPowerStackPatch.cs`，两个 Harmony 后置补丁：
  1. `SlowPower.ModifyDamageMultiplicative` → `倍率 = 1 + 0.1 × SlowAmount × 层数`
  2. `SlowPower.DisplayAmount` → 图标数字 = 当前总增伤百分比
