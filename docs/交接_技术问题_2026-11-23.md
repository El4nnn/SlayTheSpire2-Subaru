## 1. 点「立即死归」仍要求选 2 张牌保留（无用交互）

**现象**（用户原话）：「在睿智之书状态下，点击立即死归，还是会要求选两张牌进行保留，这是一个无用的设计，能不能跳过」。

**根因**：

1. `UI\ImmediateRewindButton.cs:204` → `DeathReturnSpike.ForceRewindAsync(state)`；
2. 它自伤触发致命 → `ScheduleForceEndTurn(player)`（`Rewind\Spike.cs:449 / 688`），走的是**正常结束回合**流程；
3. 回合结束相位 `BeforeSideTurnEnd` 里，`Powers\GreedAndSlothPowers.cs` 的 `GreedContractPower`
   **无条件**弹 `CardSelectCmd.FromHand(..., 0, 2*Stacks)`；
4. 紧接着回档把整回合抹掉 → 选牌与遗香都白给。

补充：这个提示来自**强欲的契约**的能力，不是睿智之书（后者只是抽牌）；全场只有这一处 `max = 2*Stacks` 的选牌。

**定论**（用户选 B：选牌框和遗香都跳过）：

- `Spike.cs` 暴露 `public static bool IsForcedEndTurn => _forceEndTurnPending;`
  （该标志在排定强制结束回合时置 true，回档还原开始才清掉，正好只覆盖那一次）；
- `GreedContractPower.BeforeSideTurnEnd` 开头判断 `DeathReturnSpike.IsForcedEndTurn`，
  为 true 就打印 `greed contract: forced end turn (rewind) -> skip retain selection` 后 return。

**验收点**：点立即死归时**不弹选牌框**、日志出现上面那行、且**不再**出现
`greed contract: N cards retained, fragrance +X`；正常按结束回合仍弹框、仍给遗香。

## 2. 立绘「只往上挪、下面空一截」：补白方向错了

**现象**（用户原话）：「你为什么只把人物往上挪，下面空那么大一截」。

**根因**：我给立绘 PNG 加**上下补白**来「让人物别太大」，而且补白全加在底部 →
内容贴画布顶、画布底部留空 → 屏幕上就是「人物飘在上半截、下方一条空带」。

对照老角色：`reinhard 1024×1654 / otto 1024×1567 / kishia 1024×1451`，
**内容占画布高 98–99%**，即画布本身就等于内容 bbox，没有补白。

**定论**（立绘构图三条硬规则，取代之前的「补白」习惯）：

| 规则 | 做法 |
|---|---|
| 画布 = 内容 bbox | 立绘高度恒等幕布高（`p_sc = bh / tex.height`），不补白 → 头顶自然冲过内框（出框是设计） |
| 只有 W/H > 1.05 才补 | 横构图（伸胳膊）补到 1.05，且**上下对称**（`cutin_pad_ratio.py` 默认 `align=center`），绝不单边补 |
| 比例对齐老角色 | 目标 W/H ≈ **0.60–0.70**；不够窄就往身体下部多裁（半身 → 大半身/全身），**不是靠补白把比例压小** |

实例：强欲司教裁到 58% 身高（769×1177 / 0.65）、帕克用全身（397×659 / 0.60）、
怠惰司教横构图 976×930（0.78 内容占高，对称补白）——三者都不再出现单边空条。

**验收点**：`preview_beatrice.py` 出的静帧里，人物头顶冲过紫色内框上沿、身体延伸到框下沿之外，**框内看不到空白带**。

## 3. 白底素材的「封闭白洞」：按面积阈值判定，别按颜色

**现象**：怠惰司教抠图后，袖子与身体之间残留一块纯白三角（6144 px）；强欲司教则是
10 个 ≥2000 px 的近白块——但那些是**白西装本身**。

**根因**：rembg 只能去掉与画布边界连通的背景，被轮廓闭合的白色区域会留下。

**定论**：用连通块 + **面积阈值**判定，不看颜色本身：

```python
lab, n = ndimage.label((rgb.min(axis=2) > 238) & (alpha > 100))
# 面积 >= 2000 且四周被深色轮廓包住的块 → 把 alpha 清零
```

实例：怠惰司教挖掉 6144 px 的袖口白洞，保留牙齿三块（364 / 310 / 1097 px）；
强欲司教的 10 个大块全是衣服（48527 / 31380 px…）→ **一块都不能挖**，否则衣服镂空。

**验收点**：`_assets\cutin\work\<id>_on_dark.png` 深底预览上看不到白色三角/白边，
且衣服、牙齿、手套等白色内容完整。
