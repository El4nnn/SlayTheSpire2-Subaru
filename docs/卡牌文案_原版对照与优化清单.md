### 1. 换行 = 一个效果一行

原版一半的牌是多行，效果之间用换行而不是逗号/分号堆一句：

```
BASH: 造成{Damage:diff()}点伤害。⏎给予{VulnerablePower:diff()}层[gold]易伤[/gold]。
BRAND: 失去{HpLoss:diff()}点生命。⏎[gold]消耗[/gold]1张牌。⏎获得{StrengthPower:diff()}点[gold]力量[/gold]。
BLOOD_WALL: 失去{HpLoss:diff()}点生命。⏎获得{Block:diff()}点[gold]格挡[/gold]。
```

### 2. 数字贴着量词，占位符前后不留空格

```
抽{Cards:diff()}张牌。        ADRENALINE 获得{Energy:energyIcons()}。
造成{Damage:diff()}点伤害。   获得{Block:diff()}点[gold]格挡[/gold]。
敌人失去{Damage:diff()}点生命。
```
（原版也有 4 处漏了空格——`CONSTELLATION`、`HIGH_FIVE`、`SOVEREIGN_BLADE`、`TRUE_GRIT`，
属于官方疏漏，不构成写法。mod 有 33 处，是明显待统一项。）

### 3. `[gold]` 上色表（原版实际用法）

- 牌堆与手牌：`[gold]手牌[/gold]` `[gold]抽牌堆[/gold]` `[gold]弃牌堆[/gold]` `[gold]消耗牌堆[/gold]` `[gold]牌组[/gold]`

- 词条：`[gold]消耗[/gold]` `[gold]保留[/gold]` `[gold]变化[/gold]` `[gold]升级[/gold]` `[gold]召唤[/gold]` `[gold]斩杀[/gold]` `[gold]击晕[/gold]` `[gold]瞄准[/gold]` `[gold]拉伸[/gold]`

```

```

### 7. 升级差分内联

```
ARMAMENTS:  [gold]升级[/gold]你[gold]手牌[/gold]中的{IfUpgraded:show:所有牌|一张牌}。
DUAL_WIELD: 将该牌的{IfUpgraded:show:{Cards}张复制品|一张复制品}加入你的[gold]手牌[/gold]。
HIDDEN_DAGGERS: 将{Shivs:diff()}张[gold]{IfUpgraded:show:小刀+|小刀}[/gold]加入你的[gold]手牌[/gold]。
```
原版**没有**「升级：…」这种追加句，也没有「（这张牌升级后…）」括号。

### 8. 术语：官方工具箱里已有的词

- 击晕（STUN）：`[gold]击晕[/gold]该敌人。`（WHISTLE）/ 说明「这个敌人在其下一回合无法行动」
- 晕眩（DAZED）：是**状态牌的名字**，不是状态效果
- 斩杀（FATAL）：是**触发词条**，「当这张牌杀死一名非爪牙敌人时触发」，不是动词
- 缩小（SHRINK_POWER）：`使敌人缩小`（官方确有这个能力）
- 不可格挡（NO_BLOCK_POWER）：是**减益**，指对方无法获得格挡
- 立刻死亡（THE_GAMBIT）：`如果你在本场战斗中受到未被格挡的攻击伤害，则立刻死亡。`
- 未被格挡的伤害（CONCOCT / ENVENOM）：`造成未被格挡的伤害时`

## 二、mod 现状与原版的偏离

### A 级：术语错误（会被玩家当成机制理解错）

1. **「晕眩 1 回合」用错词**（1 处）
   `GLOOM_SHAMAK`：`使 1 个敌人[gold]晕眩[/gold] 1 回合`
   晕眩 = 状态牌「晕眩」，官方「敌人下一回合无法行动」叫**击晕**。
   日文版这里写的是 `スタン`（正确），中文是翻译串了行。
   建议：`[gold]击晕[/gold]1个敌人。`

2. **「斩杀」被当动词用**（1 处）
   `AL_SHAMAK`：`斩杀所有生命值低于「…」的敌人`
   斩杀是触发词条（击杀时）。建议：`使所有生命值低于…的敌人立刻死亡。`

3. **「不可被抵挡的伤害」是自造词**（4 张：`BEST_FRIEND` `REGULUS` `KULGAN` `WITCH_OF_MELANCHOLY`）
   原版卡面没有这个说法：直接掉血写「失去X点生命」，日文版写 `ブロックできないダメージ`。
   建议统一为 `无法被[gold]格挡[/gold]的伤害`（或改用「使该敌人失去X点生命」的说法）。

4. **「点能量」**（1 处）`HERO`：`获得{PerCurse:diff()}点能量`
   原版能量一律是图标 `{Energy:energyIcons()}`，没有「点能量」。

5. **「费用」应为「耗能」**（5 处）：`GREED_CONTRACT` `DRAGON_TABLET` `MUSPEL` `SPHINX_CONTRACT` `CORPSE_SPHINX`
   原版卡面 33 处「耗能」，0 处「费用」；`card_keywords.json` 里自定义词条的说明也用了「费用」。

6. **「施加」应为「给予」**（9 处）：`BLUE_LIGHTNING` `PATRASCHE` `GLOOM_SHAMAK` `UL_SHAMAK` `HAKUGEI`
   `KUROHEBI` `KAFMA` `VALGREN` `UNDYING_KING_BAPTISM`（原版 68:1）

7. **「目标」应为「该敌人」**（10 处）：`STAR_ECLIPSE` `UL_SHAMAK` `SWORD_DEMON_FRIEND` `CRUSCH_FRIEND`
   `SEKHMET_WITCH` `TYPHON_WITCH` `LEY` `ELSA` `GOTZ` `UNDYING_KING_BAPTISM`（原版 13:1）

8. **「若」应为「如果」**（12 处）：原版 56 处「如果」，0 处「若」。

9. **回合归属不明**：mod 全是「回合结束时 / 每回合开始时 / 下回合」，原版一律「在你的回合结束时 /
   在你的回合开始时 / 在你的下个回合」。多人模式下前者有歧义（`THERESIA` 写成「己方回合结束时」是第三种说法）。

### B 级：排版与格式（机械可改）

1. 占位符旁空格 9 处：`STRIKE_SUBARU` `DEFEND_SUBARU` `BEST_FRIEND` `INVISIBLE_PROVIDENCE`
   `TRUE_INVISIBLE_PROVIDENCE` `AL_SHAMAK` `SWORD_SAINT_FRIEND` `SATELLA_WITCH` `CELESTIA`
2. 数字+空格+量词 33 处（`1 张`→`1张`，`2 点`→`2点`，`3 层`→`3层`，`4 次`→`4次`）
3. `手牌` 未上色 17 处、`抽牌堆` 未上色 3 处、`格挡` 未上色 2 处
4. 长牌没有换行：57 张单行超过 60 字（原版一半的牌是多行）。最长三张：
   `WITCH_OF_MELANCHOLY` 295 字、`BEATRICE_CONTRACT` 171 字、`FIRST_KNIGHT` 167 字
5. 「；」7 处（`WITCH_OF_MELANCHOLY` `GLOOM_SHAMAK` `COR_LEONIS` `CAPELLA` `KUROHEBI` `BALLROY` `SPHINX_CONTRACT`）
   → 改 `。` + 换行
6. 「——」1 处、「＝」1 处、「「」」1 处（均在 `WITCH_OF_MELANCHOLY` / `SEALING_STONE` / `AL_SHAMAK`）
7. 「升级：…」4 处（`BOOK_OF_THE_DEAD` `MIMI_FRIEND` `SPHINX_CONTRACT` `VINCENT_CONTRACT`）
   「（这张牌升级后…）」2 处（`BEATRICE_CONTRACT` `ROSWAAL_FRIEND`）→ 用 `{IfUpgraded:show:A|B}`
8. 「（可叠加）」3 处（`BLUE_LIGHTNING` `ARCHBISHOP_PRIDE` `ECHIDNA_WITCH`）→ 原版不写，层数看图标
9. 结尾不是「。」5 处（因为尾巴挂了 `{IfUpgraded}` / `{FirstKnightUsed}`）→ 需要重排语序
10. 「权能 N」中间的空格（21 张）——mod 自己的约定，统一即可，不影响读懂
