## 1. 原子斩 `Vfx/YaeAtomicSlash.cs`（新文件）

八重·天膳的**击杀演出**，三拍：**刷线 → 静止 → 散**。

| 阶段 | 终结（清场那一击） | 普通击杀 |
|---|---|---|
| 刷线 | 0→210ms：32 条细白线，两组倾角（16°/74° ±11°），每条 45~85ms 扫过，起手错开 0~90ms | 同 |
| 切 | 210ms：白闪 + 抓剪影 → 20 块不规则网格碎块**原地**出现；播 `yae_slash.mp3` | 同 |
| 底色翻色 | 90ms 内整屏 → **灰白 `#e6e4de` α0.94** | 80ms 内 → **浅粉红 `#f3cfd6` α0.88** |
| 静止 | 210 → `crumbleAt`（2.07s 死亡动画时 = 1410ms） | 到 800ms |
| 崩解 | 碎块 130ms 内向外挪 16px 并淡掉，同时 **170 粒粉末**从剪影像素上飘起 | 110 粒 |
| 收尾 | 粉末淡完 ≈ 动画结束；底色最后 160ms 淡出 | 同 |

**时长不是写死的**：`Hook.AfterDeath` 的 `float deathAnimLength` 传进 `PlayAsync(creature, full, deathAnim)`，
终结版 `clamp(anim, 1.4~3.2s)`、普通击杀 `clamp(anim, 0.8~1.3s)`。
（踩过的坑：第一版固定 0.93s，而怪物的死亡动画 2.07s → 底色提前消失，用户「感觉没出现过」。）

### 切的是剪影，不是方块（用户明确指出过一次）

`CaptureSilhouette`：
1. `visuals.Duplicate()` **只复制一次** → 塞进 `SubViewport`（透明底、尺寸 = 可视矩形 + pad 6）→
   `KillEffect.ApplyMaterial(copy, KillEffect.BuildFlatMaterial(黑))` → `UpdateMode.Once` +
   `await ToSignal(RenderingServer.Singleton, FramePostDraw)` 抓一帧；
2. 得到 `ViewportTexture`（**视口必须活到演出结束**，删了贴图就失效）；
3. 20 块 `Sprite2D` + `RegionEnabled/RegionRect` 裁到网格格子里 → 每块只显示剪影的这一格；
   抓帧失败退回纯黑方块（日志 `FALLBACK boxes`）。

网格：4 列 × 5 行，每道界线随机挪 **±30% 格宽**（≤40% 不会交叉），每块向内缩 1.8px 露缝。

### 粉末

位置**从剪影贴图的像素里抽**（`tex.GetImage()`，alpha > 0.25 的像素），所以粉从轮廓上浮起，方框里没有粉。
方向 = 离开身体中心 + 略微上浮，位移 10~56px，延迟 0~90ms，寿命 `(CrumbleMs−110)×0.6~1.0`
（保证最晚一粒也在 `CrumbleMs` 内消失），颜色 `#2a0d14`，1.1~3.2px 小方块。

### 拦截 + 音效

`Patches\EnemyDefeatSfxPatch.cs` 新增 `source is Cards.PuppetStrings` 分支：
**她打出的牌造成的所有击杀都走原子斩**，通用击杀特效完全跳过（和夏乌拉同构）。
音效在演出内部（切线合上那一帧）播 `Audio\YaeSlashSfx.cs` → `res://Subaru/audio/yae_slash.mp3`
（用户提供的 knife_swish01，+2 dB，单播放器）；演出没播（特效关掉/环境不具备）时才退回通用击杀音。

## 2. 卡片加强（未发版）

### 2.1 死神的加护（`TheresiaCard` + `TheresiaPower`）

- 原有：己方回合结束时把敌人的[虚弱]/[易伤]钉到 99。
- **新增：同一时点给所有敌人叠 `Amount` 层[中毒]**（卡面给 3，升级 4）。
- `StackType` 从 `Single` 改成 **`Counter`** —— 层数现在有意义（= 每回合叠多少毒），图标会显示数字。
  打第二张会叠层（每回合 6 层毒），要限一张得改回 Single。
- 升级现在两件事：费用 3→2 **和** 中毒 3→4。

### 2.2 大贤者（`GreatSage` + 新 `GreatSagePower`）

- 原有：减少 25（升级 35）层[魔女遗香]，一次性结算。
- **新增：打出时获得「大贤者的指引」**（`Powers\GreatSagePower.cs`，`ICorrodedPower` = 不随死归清空）。
- 结算在 `Rewind\Spike.cs` 的 `ApplyRewindBlessing`：

```csharp
var extraTriggers = player.Creature.Powers.OfType<GreatSagePower>().Any() ? 1 : 0;
var strTotal = strPer * (deaths + extraTriggers);   // 一共多一份（不是每次翻倍）
var dexTotal = dexPer * (deaths + extraTriggers);
```

| 死归次数 | 无大贤者 | 有大贤者 |
|---|---|---|
| 1 | 1 份 | 2 份 |
| 3 | 3 份 | 4 份 |

升级不影响这一条（只提高减少遗香的量）。

### 2.3 本地化（3 语言都改了，构建器强制）

构建器有本地化检查（**STS001**）：新能力/新卡缺 key 直接**编译失败**。这次补了：

- `SUBARU-THERESIA.description`（补「并给予所有敌人{PoisonPower:diff()}层中毒」）
- `SUBARU-THERESIA_POWER.description / .smartDescription`（补中毒）
- `SUBARU-GREAT_SAGE.description`（补大贤者的指引）

## 6. 环境备忘（这次踩到的）

- 中文文件**只用编辑器工具**（read/write/edit）。PowerShell `Get-Content -Raw` + `Set-Content` 会按 GBK 读整篇乱码（这次 `CombatStats.cs` 中过一次，已重写）。
- **本地化检查 STS001**：新能力/新卡必须同时补 3 语言 key，否则 `publish` 直接失败。
- `Environment` 在 `Vfx` 命名空间下和 `Godot.Environment` 冲突 → 写 `System.Environment`。
- `ICorrodedPower` 在 `Subaru.SubaruCode.Rewind`（不是 Extensions）。
- `upload.bat` 末尾有 `pause`，脚本里要从 `release\workshop\Subaru` 直接调 `ModUploader.exe upload -w .`。
