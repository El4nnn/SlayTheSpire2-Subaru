## A. 根因条目（L2 · 一条一节）

```markdown

**现象**（用户原话）：「<原话>」；<补充一句客观描述：什么操作、什么界面>。

**根因**（证据落到 文件:行 / IL / hook 相位 / 唯一写入方）：

1. `<文件:行>` 做了什么 —— <调用链上游>;
2. `<文件:行>` 只判断了 <A>、没判断 <B> —— <为什么这是关键>;
3. 触发组合是 <X> + <Y>，所以只有 <场景> 会炸。

**定论**：<改在哪一句、为什么不是别处>。
被否掉的方案：<方案>（原因：<代价：音效/顿帧/多人/沉没成本>）。

**验收点**：日志出现 `<关键行>`；**不再**出现 `<旧行>`；<数值/画面判据>。

**证据**：

    <日志片段 / IlDump 输出>

```
