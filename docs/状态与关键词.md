## 一、核心机制：死亡回归（死归）

| 项目 | 内容 | 状态 |
|---|---|---|
| 死归触发 | 生命归零时回档到「存档点」 | ✅ |
| 死归代价 | 每次死归，往手牌加入 1 张[魔女瘴气]（只发一次，消耗掉了不会再补），**并累积 20 层[魔女遗香]** | ✅（2026-11-23 更正） |
| 死归次数 | **不限上限** | ✅ |
| 存档点 | 默认不可控；「迷失」可把存档点定为本回合 | ✅ |
| 癫狂判定 | **手牌中的[魔女瘴气]数量 ≥ [傲慢]层数**时触发；触发后清空手牌中的[魔女瘴气]，[傲慢] **不减少**（永久累积） | ✅ |
| 癫狂期间死亡 | **本局直接结束（真死）** | ✅ |

### 魔女瘴气的使用限制

- 死亡回归把它放进手牌时的那 **20 层[魔女遗香]**是**死归本身的代价**，这张牌**不带权能标签**（2026-11-23 更正：`CurseWitchMiasma.cs:31`、`Spike.cs:436`）
- **不可丢弃**（Harmony 拦截 `CardCmd.Discard`；[保留] 只挡回合结束弃牌，这一层挡所有强制弃牌）
- **不能以物品打出**
- **不能被「消耗任意一张牌」的牌消耗**（[忧郁魔女] 的选牌已排除魔女瘴气）
- **只能被明确指定消耗[魔女瘴气]的牌消耗**（[首席骑士]、[契约·贝蒂]；[英雄] 自 0.1.2 起只读取不消耗）

> 设计意图：它是「只增不减」的计数器，同时也是唯一的泄压阀——专门设计的消耗牌才能清掉。
