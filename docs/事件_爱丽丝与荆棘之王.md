## 1. 结构

三个选项并列；①② 是**两段式**，③ 一步结束。版式照原版事件（真理石板 / 酷刑博物馆 / 滑脚木桥）：

- 选项**标题只写动作**：`数星星` / `握住他伸出的手` / `转身离开` / `获得吾星`
- **代价与收益写在标题下面那行小字**：`失去[red]3[/red]点最大生命。` / `获得[gold]荆棘王冠[/gold]，并将诅咒[red]受伤[/red]加入你的牌组。`
- 点进中间页后正文换成该选项的台词，按钮是 `获得吾星` / `获得荆棘王冠`，点它才真正结算
- 结算完进结果页（叙述 + 括号小字）

中间页与结果页的文案见 §2。

**出现率**：事件房抽完之后，按 `Patches/WitchContractChainPatch.cs` 里的 `ModEventOddsPatch` 强插 ——
一次性掷 `[0,1)`：`[0, 0.15)` 给魔女的茶会（15%），`[0.15, 0.25)` 给本事件（10%）。
两个区间互斥，所以不会同一次刷出两个；本事件「本局已走过」后不再强插。
注意这是**额外强插**的概率：本事件仍在引擎的随机池里，所以总出现率 = 池子里自然抽到的份额 + 10%。
若要精确等于 10%，需要给事件加 `IsAllowed => false`（像魔女的契约那样只走强插）。

| 选项 | 代价 / 获得 |
| --- | --- |
| ① 数星星 | 获得遗物【吾星】；失去 3 点最大生命 |
| ② 握住他伸出的手 | 获得遗物【荆棘王冠】+ 原版诅咒【受伤】 |
| ③ 转身离开 | 什么都不发生 |

**右侧文字底板**：`Patches/EventTextPanelPatch.cs` 在 `NEventLayout._Ready` 之后，
给「正文 + 选项」的公共祖先垫一块半透明圆角 Panel（`#0A0D14` 74% 不透明、紫色 2px 描边、外扩 18px、`MouseFilter=Ignore`）。
定位用全局矩形 + 逆变换，跳过容器父节点，避免被 VBox 排成子项。

## 2. 文案（中文原文）

**事件描述**

> 夜色中，一个绿发男人独自站在山丘上，凝视着空无一物的黑暗。你走近时，胸口突然传来一阵尖锐的刺痛——看不见的荆棘正缠上你的心脏。
>
> 男人没有回头，只是低声说：「……你不是吾星。但你也看得见星星，对吧。」

**① 数星星**（小字：失去 3 点最大生命。）
中间页正文：「比起眺望黑暗，数夜空中的星星不是更能安心吗。」→ 按钮：获得吾星（小字：获得吾星。失去 3 点最大生命。）
结算：你陪他站了一会儿。荆棘的痛楚没有消失，但似乎……不再收紧了。
（那根刺仍然在，但它记住了你的声音。）

**② 握住他伸出的手**（小字：获得荆棘王冠，并将诅咒受伤加入你的牌组。）

结算：「余允许。允许与你有关的一切。」荆棘缠绕上你的手腕，像一枚戒指，也像一道锁链。

**③ 转身离开**（小字：什么也不会发生。）
结算：你没有回头。身后的荆棘在黑暗中沙沙作响，像一声很轻的叹息。
（你听见他说：「……果然，余的星只有一个。」）

## 3. 遗物与诅咒

| 名称 | 稀有度 | 效果 | 本地化键 |
| --- | --- | --- | --- |
| 吾星 / My Star / 吾が星 | Event | 每次[死归]回档后，回复 6 点生命 | `SUBARU-MY_STAR` |
| 荆棘王冠 / Thorn Crown / 茨の王冠 | Event | 战斗开始时获得 3 层[荆棘]；每次[死归]后，再获得 2 层[荆棘] | `SUBARU-THORN_CROWN` |
| 受伤 / Injury / 怪我 | — | 原版诅咒，直接由 `Models.Cards.Injury` 发放 | 游戏本体自带 |

- 两件遗物都是 `RelicRarity.Event`，不进随机奖励池（和「贝蒂的守护」同款）。
- 吾星小字：愿星光与你同在 / May the starlight be with you. / 星の光が、あなたと共にありますように。
- 荆棘王冠小字：王权的背后，付出了什么样的代价，无人知晓 / No one knows what price was paid behind the crown. / 王権の裏で、どんな代償が払われたのか、誰も知らない。
- 数值（6 / 3 / 2）是实现时定的，用户尚未确认，随时可改。
- 图标已全就位（抠图 + 去水印 / 白底抠图）：`images/relics/{my_star,thorn_crown}.png`（94）、`*_outline.png`、`big/*.png`（256）；源图在 `_assets_work/{my_star,thorn_crown}_src.jpg`。

## 5. 临时补丁：第一个「?」房必出本事件（2026-11-19）

`Patches/FirstUnknownEventPatch.cs`，`FirstUnknownRoom.Enabled = true` 时生效：

- 只认**第一章、本局还没走过任何「?」房**的那一个「?」
- 先把该房的候选房型裁成只剩 `RoomType.Event`（否则掷到战斗/商店时 `ModifyNextEvent` 不会被调用）
- 再把事件强制换成 `AliceAndThornKingEvent`；**先古事件（`AncientEventModel`）不替换**
- 日志：`[Subaru] first '?': forced to Event room` / `[Subaru] first '?': forcing SUBARU-ALICE_AND_THORN_KING_EVENT (was …)`

测完关掉的方式：把 `Enabled` 改成 `false`，或者直接删掉这个文件（它不依赖别的代码）。
