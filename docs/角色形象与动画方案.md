# 昴 · 角色形象与动画方案（奶蛙级）

> 📌 **superseded** ｜ 最后核对：2026-11-23 ｜ 被 动画制作方案_v2 取代

> 目标：不做 Spine 编辑器级别的正剧动画，做到「进游戏能用、看着不别扭」。
> 对标物：奶蛙 mod —— 27 骨 / 17 插槽 / 7 段动作 / 单页图集。
> 前提：本机没有 Spine Pro，所以骨架 JSON 由脚本生成、动画关键帧手写数值。

---

## 0. 先说清楚"能用"的标准

验收只看这 6 条，别的都不算问题：

1. 战斗里不闪白、不浮空、脚不穿地
2. 引擎要的 7 段动作名都能找到（`idle_loop / low_health_loop / attack / cast / hurt / die / relaxed_loop`）
3. 和原版角色同高、同站位（脚底 y≈0，重心 x≈0）
4. 受击、死亡、低血量变暗表现正确
5. 单页贴图 ≤ 2048²，进战斗不掉帧
6. 不用改游戏本体，只靠 mod 自己的资源和代码

---

## 1. 骨骼设计（18 骨 / 15 插槽）

正面 2D，骨骼从粗到细，够用就行：

```
root
└─ hips                 重心，唯一做位移动画的骨
   ├─ torso             上身（前倾/后仰）
   │  ├─ chest          胸口（呼吸缩放）
   │  │  ├─ neck
   │  │  │  └─ head     头 + 前发
   │  │  ├─ hair_back   后发（错相摆动）
   │  │  ├─ arm_l_u → arm_l_f   左上臂 → 左前臂+手
   │  │  └─ arm_r_u → arm_r_f   右上臂 → 右前臂+手
   │  ├─ coat_l         外套下摆左
   │  └─ coat_r         外套下摆右
   ├─ leg_l_u → leg_l_f 左大腿 → 左小腿+鞋
   └─ leg_r_u → leg_r_f 右大腿 → 右小腿+鞋
```

插槽（= 贴图块，绘制顺序从后到前）：

| # | 插槽 | 挂在骨 | 备注 |
|---|---|---|---|
| 1 | hair_back | hair_back | 在后发里，被头挡住 |
| 2 | coat_l / coat_r | coat_l/r | 在腿前面、身体后面 |
| 3 | leg_l_f / leg_r_f | 对应小腿 | 连鞋 |
| 4 | leg_l_u / leg_r_u | 对应大腿 | |
| 5 | torso | torso | 身体+外套主体+脖子 |
| 6 | arm_l_u / arm_l_f | 对应臂骨 | 前臂在身体前面 |
| 7 | arm_r_u / arm_r_f | 对应臂骨 | 同上 |
| 8 | head | head | 脸+前发+眼 |
| 9 | weapon（可选） | arm_r_f | 只在 attack 出现 |

**为什么不做更细**：更细就得做关节遮罩、形变网格（mesh attachment），那是奶蛙也没有的水平；18 骨足够做出呼吸、挥击、施法、受击、倒地五种姿态。

## 2. 动画表（7 段，关键帧手写）

spine 是曲线插值，5–6 个关键帧就能很顺，不需要逐帧。

| 动画 | 时长 | 关键帧 | 动作拆解 |
|---|---|---|---|
| `idle_loop` | 2.0s | 5 | hips 上下 ±6、chest 缩放 1.00→1.02→1.00、head 左右 ±2°、hair_back/coat 错相 ±4° |
| `low_health_loop` | 1.5s | 5 | torso 前倾 15°、hips 下移 20、手臂下垂、呼吸幅度加倍 |
| `attack` | 1.2s | 6 | ①蓄力：arm_r_u 后拉 25°、torso 后仰 5° → ②出招：arm_r_f 前挥 −70°、torso 前倾 8°、hips 前移 25 → ③收招：回位 |
| `attack_heavy` | 1.5s | 6 | 同上但幅度 ×1.4，加 hips 上抬（起跳感） |
| `cast` | 1.6s | 5 | 双臂上举 70°、head 后仰 8°、hips 上浮 10、chest 缩放 1.05（权能爆发） |
| `hurt` | 1.0s | 3 | torso 后仰 10°、head 歪 6°、hips 后移 15 |
| `die` | 2.3s | 6 | ①跪：hips 下移 120、双腿折叠 → ②前扑：root 旋转 75°、整体贴地 |
| `relaxed_loop`（可选） | 1.5s | 4 | 站直、手插兜、轻微晃动 |

**父级传递**：只动 `hips / torso / chest / head / 四根臂骨 / 四根腿骨`，其余靠父级带动，关键帧数量不会爆炸。

## 3. 美术生产（一天内能出）

1. **一张全身立绘**：ComfyUI SDXL，832×1472 竖图，纯白底、正面站姿、双臂略分开（方便切）
2. **抠背景**：白底二值抠图 + 1px 羽化
3. **切件**：按上表 15 块切（矩形/多边形框），每块向外多留 **8–12px 重叠**，靠层级顺序遮挡——这是宽关节不露缝的关键，奶蛙的 atlas 里每个 region 都带 `offsets` 就是干这个
4. **打包**：1024×2048 单页，按名字生成 `.atlas` 文本（页尺寸、每块 bounds/offsets/rotate）

## 4. 工具链（我写，2 天）

| 工具 | 作用 |
|---|---|
| `parts2spine` | 读 `parts.json`（图块、所属骨骼、偏移、尺寸）+ 动画表 → 输出 `subaru.json`、`subaru.atlas`、`subaru.png` |
| viewer 加第 7 个条目 | 把生成的骨架直接丢进现有查看器，逐段调关键帧（改一个数值刷新就能看） |
| `spine2godot` | 生成 `res://scenes/creature_visuals/subaru.tscn`（SpineSprite + Bounds + IntentPosition/TalkPosition 标记） |
| 尺寸标定 | 在 viewer 里对比铁甲战士（约 1200 单位高）反推 atlas scale，保证同高 |

产出物结构：

```
res://animations/characters/subaru/
    subaru.json       骨骼 + 7 段动画
    subaru.atlas      图集描述
    subaru.png        单页贴图
res://scenes/creature_visuals/subaru.tscn
```

## 5. mod 侧接入（1 天）

| 文件 | 改动 |
|---|---|
| `Character/Subaru.cs` | `PlaceholderCharacterModel` → `CustomCharacterModel`，override `CustomVisualPath` 指向 `creature_visuals/subaru` |
| 同上 | 补 `CustomEnergyCounterPath / CustomRestSiteAnimPath / CustomMerchantAnimPath`（这几项可以继续借用铁甲战士的） |
| 同上 | `AttackAnimDelay`（attack 1.2s → 约 0.35 是命中帧）、`CastAnimDelay`、`PowerUpAnimDelay` 按上表调 |
| `AnimationStates` | 若引擎要 `attack_heavy`，在 `SetupCustomAnimationStates` 里注册 |

引擎侧契约（已从 `sts2.dll` 反查确认）：
`CreateCustomVisuals()` 返回 `NCreatureVisuals`；`SetupCustomAnimationStates(MegaSprite)` 返回 `CreatureAnimator`，内部用 `idle/lowHealthIdle/attack/cast/hurt/die` 这套 `AnimState`。

## 7. 风险与兜底

| 风险 | 兜底 |
|---|---|
| 关节切开露缝 | 每块留 8–12px 重叠 + 层级顺序；仍露则在关节处加一小块"关节补丁" |
| 手写 JSON 在 slot/skin 上出错 | 有 viewer 可以秒验；解析失败会直接报错 |
| 神韵不像昴 | 先出 3 张立绘给你挑，定稿再切；不动画阶段返工成本低 |
| 尺寸对不上原版 | 用 viewer 同框对比标定，一次到位 |
| 7 段里某段引擎没触发 | 缺的段用 fallback（引擎会退化到 idle），不影响进游戏 |

## 8. 需要你拍板（会直接影响零件画法）

1. **风格**：干净二次元平涂（好切、好做形状，推荐）还是塔二那种厚涂？
2. **服装**：原作黑橙运动服，还是换成异世界便装？
3. **武器**：空手+魔法（最省，推荐）/ 小刀 / 鞭子（基尔提之鞭，鞭子动画难做，会拖到 2 天）
4. **要不要 `relaxed_loop`**（营火/商人的待机）：不做就借用 `idle_loop`，能省半天
