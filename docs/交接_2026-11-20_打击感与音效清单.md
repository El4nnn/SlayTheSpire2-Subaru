### 1.7 die（死亡动画）：坑「点死归按钮抬手」

### 1.8 操丝术专属演出：四刀切屏（2026-11-20 深夜）

需求原话：「以此出现四根线条，轻微斜着把屏幕分成多块，然后每出现一根线条，屏幕就沿着这根线分开一点」。

- 代码：`Vfx/ScreenCut.cs`（shader 内嵌字符串）；调用点 `Cards/PuppetStrings.cs` 的 `OnPlayCard`（`Start` → 每段伤害前 `Cut()` → `finally Finish()`）。
- 做法：一块全屏 `ColorRect` + `canvas_item` shader，用 `hint_screen_texture` 读**已经画好的画面**，
  按 4 条线切成 5 块、每块整体平移，没被任何一块认领的像素 = 缝 → 虚空色 + 切口发光。
- **为什么不沿用击杀那套「截屏 + 多边形贴图」**：截屏会把画面冻住 0.5s，而这是 1 费普通攻击、每回合都可能打，
  冻住就等于看不到伤害数字/受击。读屏幕纹理没有这个问题（代价：要在 shader 里做反向查表）。
- 几何：每刀 = 单位法线 n + 偏移 d（屏幕像素）。点 p 属于第 k 块 ⟺ 它在**恰好 k 条**线的正侧
  （`k = Σ (dot(n,p) - d > 0)`）。第 k 块位移 `Σ_j (j<k ? +A_j·n_j : −A_j·n_j)`，相邻两块各让 A_j → **缝宽 = 2A_j**。
  因为是「目标像素不知道自己原来属于哪块」，fragment 里对 k=0..4 试 `q = p − disp(k)`，`q` 落在第 k 块才采样。
- 时序：出线 70 ms（沿线条方向拉开）→ 分开 85 ms（`easeOutBack` 过冲 1.25）→ **停留 420 ms** → 合拢 160 ms（2026-11-20 23:5x 用户定：分割要停久一点）。
  每刀由**伤害段**触发，所以节奏天然跟多段伤害走（想改快慢改 `Cut()` 的调用位置，不是改常量）。
- 参数（用户在 `screen_cut.html` 里定的，2026-11-20 23:2x）：基准角度 **90°（线条水平、屏幕切成横条）**、散布 0.77、角度抖动 ±5.5°、位置抖动 0.1、每刀 **8.5 px**（按 900p 设计，实际乘 `屏幕高/900`；缝宽 = 2A = 17 px）、线宽 1.3、光晕 8 px / 强度 0.25、缝光 0.92、刀光白闪 **0.30（45 ms 高斯，整屏加白）**。
  4 条线每次打牌**重新摇**（位置/角度都抖一点），所以每刀的切法不完全一样。
- 兜底：① `Shader.GetShaderUniformList()` 里看不到 **`screen_size`** 就不播（防 shader 编译失败 → 整屏白）。
  ⚠️ 探针**不能用 `screen_tex`** —— `hint_screen_texture` 的 uniform 引擎不许外部设置，根本不会出现在那张表里，
  拿它当探针会永远判「没编译过」，第一次上线就是这么静默失败的（日志 `shader uniform screen_tex missing，本次不播`）；
  ② 4 s 硬超时自动释放；③ 不 await 演出，卡牌结算不受影响；④ 上一发没播完又打一张 → 收掉旧的，不叠层。
- 预览台：`_anim/review/screen_cut.html`（双击打开）。可以拖入真实截图、直接拖线条/端点、调所有滑杆、导出 JSON；
  支持 `?t=毫秒` 定位到某一刻（我用无头 Edge 截图核对过 +150/+430/+545/+650/+760 五帧）。

### 1.9 打击特效总开关（2026-11-20 23:5x）

设置页 → 特效 → **打击特效**（`visual.hitFx`，默认开），管的是「音效开关」和「击杀特效开关」以外**所有** mod 演出：

| 被管的系统 | 关掉后的行为 |
|---|---|
| `Vfx/HitFeel` 顿帧 / 抖屏 / 镜头推 / 命中光爆 / 受击闪白 | 不播；`AoeImpact`/`JoltDown` 也直接返回 |
| `Vfx/SpellVolley` 弹幕（含「等弹幕命中才出伤」） | 不播；卡牌走原版 `DamageCmd.Attack(...).WithHitCount(n)`，伤害立刻结算 |
| `Vfx/ScreenCut` 操丝术切屏 | `Start()` 返回 null，牌照常打 |
| `Vfx/CardVisuals` 等待结算时的卡牌虚化 | 不虚化 |

不受影响：打击音效（`audio.hitSfx`）、击杀特效（`visual.killEffect`）、死归的紫光/死亡动画。
实现要点：**四个系统的 `Enabled` 都改成「自己的开关 && 总开关」的属性**（原来是非空字段），
因为卡牌是用 `SpellVolley.Enabled` 判断「要不要等弹幕再出伤」的 —— 若只拦播放，
关掉总开关会变成「弹幕不播 + 伤害也不结算」。`SubaruVisualSettings.HitFxEnabled` 用可空 bool `bool?`，
这样旧存档（没有这个字段）反序列化后仍然按「开」处理，不会凭空变成关闭。
