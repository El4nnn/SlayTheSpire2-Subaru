## 一、逐帧量化（亮度 / 柱宽，像素）

| 效果 | 8 帧亮度 | 柱宽（中线） |
|---|---|---|
| holy_pillar | 0.087 → **0.209** → 0.195 → 0.184 → 0.116 → 0.091 → 0.087 | 0, 0, **37**, 36, 34, 22, 10, 9 |
| divine_smite | 0.087 → 0.098 → **0.149** → 0.140 → 0.106 → 0.095 | 0, 0, 12, 13, 0, 0 |
| radiant_barrage | 0.088 → 0.098 → 0.123 → 0.108 → 0.125 → 0.098 | 0, 5, 31, 28, 33, 3, 0 |

**三条可直接借鉴的规律**

1. **到峰值只要 1 帧**（第 2 帧就满亮度），之后是**长尾**（4~5 帧缓慢衰减）；
2. **柱宽不是匀速收窄**：37 → 36 → 34 → **22 → 10 → 9** —— 先几乎不变，最后两级骤降，
   而且**最后还会留一根 9px 的细丝**，不是整体消失；
3. **地面先有环、再有池**：起手是细椭圆环，命中后变成**亮光池**（实心椭圆），不是一条线圈。

## 二、形状上的差异（我们 vs 他们）

| 项 | ParticleFX | 我们现在 |
|---|---|---|
| 柱体轮廓 | **上窄下宽**（火焰/瀑布形），底部蓬松堆积 | 上下对称收尖（`beam_core.png` 是 sin 钟形） |
| 地面 | 细环 → **亮光池** | 细环（Line2D 椭圆） |
| 尾段 | 细丝残留 3~4 帧 | 整体 dissolve 淡出 |
| 终结 | **放射速度线**（24~40 根长短不一）+ 多层同心环 | 4 帧冲击（12 根尖刺）+ 白屏负片 |

## 三、三条改动（2026-11-22 已落地；其中「上窄下宽」当天被用户否掉，见 §四）

| # | 改动 | 影响文件 | 估时 |
|---|---|---|---|
| 1 | `beam_core.png` 改「上窄下宽 + 底部蓬松」；新增 `beam_pool.png`（地面光池） | `_tools\gen_vfx_textures.py` + `BallroyBeam` | 20 分 |
| 2 | 主柱淡出后**保留一根细丝** 200ms（宽 3~6px、α 0.35） | `BallroyBeam.TailAsync` | 15 分 |

> 2026-11-22 用户「做」之后实现：新增 eam_pool.png 地面光池（后调暗到 α0.42）、TailAsync 末尾加 320ms 余丝、impact 尖刺 12→24。
