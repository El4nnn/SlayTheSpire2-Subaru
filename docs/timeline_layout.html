时间线节点位置关系

怎么读这张图

  • 每一行是一个 时代（EpochEra），从上到下按时代编号排序。
  • 每个方块是一个历史节点，横向位置 = EraPosition，数字越大越靠右。
  • 金色方块是 Subaru 自己的节点：异世界召唤？！（繁盛0）与 死亡回归（繁盛2）。
  • 两个节点的序位都是运行时算的：从 3 开始找空位，被占用就 +1（避让原版和别的 mod）。
