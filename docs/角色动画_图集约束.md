# 角色动画：图集必须单页（2026-11-13 定稿）

> 📌 **canon** ｜ 最后核对：2026-11-23 ｜ 图集硬约束：单骨架单页 / 4096² / mipmaps 关

## 一句话结论

**在这个环境里（STS2 β 0.111 + spine-godot 4.2 / MegaDot 4.5.1），Subaru 的整条骨架必须把
所有帧放进同一张图集页。跨页 = 非第 0 页的动画画不出来，还会留下上一帧的残影。**

## 症状（踩过的坑长什么样）

- 待机时角色在「抽搐」、像好几个姿势叠在一起
- 头顶浮着一只鞋、腰边浮着一只手 —— 这些是**其它页上那一帧的残留 quad**，位置固定、每帧内容都不同
- 攻击**完全没有动作**（帧在第 1 页 → 什么都画不出来，看起来就是闪一下）
- 录像逐帧量化：相邻帧（1/30 s）质心在 119–210 px 之间乱跳，但整体外框固定

## 证据链

| 版本 | 结构 | 结果 |
|---|---|---|
| 静态版（每动作 1 帧） | **1 页**，6 区域 | 干净 |
| 3 页版（idle=第0页 / 战斗=第1页 / 死亡=第2页） | 3 页 | **待机干净**，攻击空白闪烁 |
| 单页低帧率（46 帧） | 1 页 | 干净 |
| **单页全帧数（229 帧，当前定稿）** | **1 页** | **全部正常** |

另外排除了这些（都是实测，不是推测）：

- 图集重打包把帧搞坏 → 270 区域逐像素比对，零差异
- 皮肤坐标写错 → 229 个共有附件 x/y/w/h 零差异
- pck 里的 atlas 与工程不一致 → 逐字节相同
- `.ctex` 是旧的 → 导入记录 source_md5 与实际 PNG 全部匹配
- 变速播放把 timeScale 漏在 8× → 出问题的几场日志里**没有** `rewind animation played`，演出没跑过

## 当前定稿的打包参数

```
页数        1
页尺寸      4096 × 4096
帧像素      原图的 94%（attachment 的 width/height 不变 → 屏幕大小/位置不变，只是略软）
区域数      229（idle 61 / attack 19 / cast 48 / hurt 26 / die 80 / revive 80 倒放）
占用        90.5%
纹理        BPTC、mipmaps 关闭、detect_3d=0
显存        16.8 MB      pck 30.7 MB
```

atlas 每个区域必须写成：

```
subaru_0.png
size:4096,4096
format:RGBA8888
filter:Linear,Linear
repeat:none
idle_0000
bounds:x,y,w,h
offsets:0,0,w,h      ← 游戏自带 ironclad 也是这么写的
```

## 硬性禁止

1. **不要把同一个骨架的帧拆到多页**（哪怕「每个动画独占一页」也不行，实测第 1 页起就是黑的）
2. **不要开 mipmaps**：RitsuLib 会把全局 2D 纹理过滤设成 `linear_mipmap`，紧排图集一开 mip 就会采到邻居
3. 图集页数改成 1 页时，记得删掉旧的 `subaru_N.png` 及其 `.import`，否则会被打进 pck
4. 新增页时 `.import` 必须手动补预设（`compress/mode=2`、`high_quality=true`、`mipmaps/generate=false`、
   `detect_3d/compress_to=0`），否则 Godot 用默认「无损 + 非 VRAM」，显存翻 4 倍

## 脚本

- `_tools/tmp/onepage.py` —— 单页打包（自动从 1.00 往下找能塞进一页的最大缩放比）
- `_tools/tmp/render_sheet.py` —— 按 atlas + json 把每个动画重画成连拍图，用于本地核对

## 已决定不做（别再重新提）

- **按卡牌分动作**（连续攻击接另一套动作 / 魔法攻击接专属动作）—— **2026-11-13 决定不做**。
  原因：多段命中的牌会让引擎对同一段攻击**重复触发多次**（`NCreature.SetAnimationTrigger` 只是转发
  `animator.SetTrigger`，没有去重；原生的 `CreatureCmd.TriggerAnim` 被几百个 `OnPlay` / `AfterAttack`
  协程各调一次）。原生角色也这样，只是骨骼动画重播像「连续挥击」，而我们的逐帧翻页会硬切回第一帧，很刺眼。
  要修就得自己拦触发器（约 15–40 分钟），既然原生也不解决，就都不做了。
  当时筛好的牌单留在 [`连续攻击与魔法牌筛选.md`](连续攻击与魔法牌筛选.md)，只作参考。
